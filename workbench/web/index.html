Laptop control through Tailscale
Start this workbench on the desktop once. Then use the same controls from your laptop’s browser. Remote Desktop is not needed. Keep the desktop awake.
The control service binds only to loopback and your Tailscale address. It does not use public port forwarding or Tailscale Funnel. The pairing key grants control; share it only with your own devices.
