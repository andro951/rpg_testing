Native llama.cpp worker
Only model storage is selected here. Runtime, tests, results, logs and settings stay with this repository.
Existing GGUFs are used in place. The program never copies them or silently selects a C-drive model folder.
Never publish private saves, real patient/student records, credentials, or explicit content to this public repository.


Laptop control through Tailscale
Start this workbench on the desktop once. Then use the same controls from your laptop’s browser. Remote Desktop is not needed. Keep the desktop awake.
The control service binds only to loopback and your Tailscale address. It does not use public port forwarding or Tailscale Funnel. The pairing key grants control; share it only with your own devices.
First launch prerequisites
The launcher needs Python and asks before preparing its private environment. Use the model browser for downloads; use the runtime browser for official GPU builds. Neither installs drivers or makes system-wide changes.
Official llama.cpp runtimes
Install only after choosing a build. For a GTX 1080, prefer a CUDA 12 build rather than CUDA 13. Runtime compatibility is verified before tests; release metadata is not a hardware guarantee. Downloads stay inside this repository.
