## Review record required before marking complete

Record the reviewed real output/evidence reference, evaluator version, detailed assessment, fixture results, original-score comparison, reviewer conclusion and any unresolved contract question. A synthetic known-pass fixture must be labeled synthetic. Each variant has independent progress fields in `contracts.json`; sharing a function does not imply shared completion.
