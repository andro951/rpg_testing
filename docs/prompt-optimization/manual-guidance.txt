Optional manual optimizer guidance

Prompt Optimization includes an optional manual-guidance text box for either
Codex or Local model prompt writing. New sessions and Apply settings use
settings.manual_guidance through the existing configuration/API paths. An
absent, empty or whitespace-only value adds nothing to optimizer messages.
Clear the field and apply settings while stopped to remove saved guidance.

Nonempty text is saved in session settings and configuration-history evidence.
Every later generation request records its exact guidance, digest and
prompt_writer_only scope. It is appended after LPIL assembly, so marker-shaped
user text is preserved literally and is not lowered, normalized or substituted.
It participates in the existing token/context budget and is never silently
truncated or dropped with old candidate history.

Guidance supplies broader context to the optimizer while retaining the one
selected starting example, origin gate and full configured task-type coverage.
CandidateBackend does not append the guidance to benchmark target requests.
Benchmark controls, parser, validator and scoring are unchanged. Codex keeps
the same saved session thread and receives the guidance on each writing round.
Prompt writing still has no elapsed timeout; manual Stop remains available.

The versioned dot_patch_v1 operation contract can use the existing reviewed
target selector and scope freezer. Its normal strict dot interpreter remains
the evaluator; this does not introduce tolerant outer JSON or path recovery.
