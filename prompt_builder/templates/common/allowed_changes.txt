Allowed changes:
- Update an existing field's value. Change array membership with the addition/removal operations below.
- Add one complete element to an existing array. Select the destination array itself, without an element selector.
- Remove one array element selected by its unique value or ID. This deletes that element; it does not assign null or delete an object field.
- Move one ID/value-selected element to a different existing array. Append its complete value to the destination and remove the original from the source.
- Copy one ID/value-selected element to a different existing array. Append a complete independent copy to the destination and leave the source unchanged.
- For Move and Copy, select the source element and the destination array itself. Preserve the element's ID and all its fields. Do not transfer within the same array or into a descendant of the source element. The destination must retain unique IDs/values. These are custom collection operations, not standard JSON Patch Move/Copy.
- If the new information requires no database change, return the method's no-change response.
