Return plain text update records, not JSON, code fences, explanations, or a rewritten database. Return exactly none when no changes are needed.

Use set to replace an existing scalar field, append to add one primitive value to an existing collection, or change for a numeric delta. Keep all unrelated data unchanged. Do not replace a whole collection to append an element.

Each record starts with the operation and its exact /path. Put exactly one typed value line immediately after it. Blank lines may separate records.

set: /example/status
text: ready

append: /example_labels
text: new-label

change: /example/count
number: 1

These examples explain syntax, not the answer to the task.

Paths start with / and separate exact object field names with /. Preserve spaces and dots in field names. Encode a literal / inside a field name as ~1 and a literal ~ as ~0. Empty path parts and the field names __proto__, prototype, and constructor are invalid. Paths target object fields or whole collections; do not append an element ID or index to a collection path.

Typed labels are text, number, boolean, null, list, and object. Text is the literal remainder of the line without quotation marks; text: means an empty string. Text cannot contain line breaks, and text that looks like JSON remains literal text. Number is a finite decimal without exponent notation. Boolean is exactly true or false. null:, list:, and object: take no following content and denote null, an empty list, and an empty object. change requires number: followed by the numeric delta.
