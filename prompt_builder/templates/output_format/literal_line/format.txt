Output format:
Return only update lines, without explanation or Markdown. Return exactly none if no change is needed. Each complete update occupies one physical line.
For an existing field: set dot.path: text:literal text through end of line
For an existing non-string field: set dot.path: json:JSON_value
To append one element: append dot.path: text:literal text OR append dot.path: json:JSON_value
To remove an element: remove dot.path
Use text: only for strings. Text starts immediately after text: and continues to end of line; do not add outer quotes. Quotes can be written literally. Decode the requested input text before writing it: do not copy JSON escape characters as literal text.
Text escapes: write \\ for one literal backslash, \n for a newline, \r for a carriage return, \t for a tab, and \s for one space. You may write \" for a quote, but a literal quote needs no escape. These are the only backslash escapes. To represent a literal backslash followed by n, write \\n, not \n. Leading and internal spaces may appear literally; write each trailing space as \s so it is not lost. Empty text is text: with nothing after it.
Use json: for a complete non-string JSON value; objects and arrays use normal JSON syntax. Do not use json: for a string. Paths follow the dot-path rules above. Apply operations in order.
Examples, unrelated to the task:
set sample.note: text:He said "hello": yes
set sample.note: text:first\nsecond
set sample.note: text:literal \\n
set sample.note: text:ends with two spaces\s\s
set sample.count: json:4
append sample.items: json:{"item_id":"new","value":1}
remove sample.items.old
Return only the required changes.
