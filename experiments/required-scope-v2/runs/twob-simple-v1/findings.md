# 2B short-instruction experiment

The concise `twob_short_v1` instruction block is a separate copy rooted in the preserved original dot-JSON recipe. It keeps the JSON operation-array contract, identity resolver, parser, semantic scoring, 32K context and sampling. It was motivated by existing 2B development outputs that left reserved IDs unencoded or targeted an ID field. No heldout output was used to write the copy.

The predeclared development screen reused four original Qwen3.5 2B Q8_0 observations across two reserved-ID tasks, two presentations and one repetition. The original failed all four. The short copy passed two of four, both in full-path presentation, with no inconclusive results. It met the predeclared screen; this is development evidence, not an unbiased final performance estimate.

The separately frozen fresh verification had two simple-ID tasks, each in normal JSON and full-path presentations, one repetition, and matched original/copy arms. The original passed 2/4 observations and the copy passed 1/4: one pass→pass, one pass→fail and two fail→fail. Both arms passed the full-path nested update-plus-add case, but the copy failed that case in normal JSON while the original passed it. Both arms failed both presentations of the exact difficult-text-plus-removal task. No candidate gain appeared on this tiny fresh set. Four observations arise from only two tasks and are not four independent tasks; the result does not rule out further 2B-specific optimization.

All four new development observations and all eight verification observations were captured, backend-reported full GPU, completed and had no recorded timeout. Reused development baselines were checked against model artifact, target, source, expected state, sampling and 32K context. Verification pairs were checked for matching state/schema/task, model artifact, target, sampling and context; both evaluators and independent reference applications passed before inference. The verification candidate and fixtures were frozen before the development output and not revised afterward. Both runs finished and released the GPU before the predeclared 21:35 desktop-clock stop.
